# Проверка на реальных фото из супермаркета

84 фотографии полок, снятые телефоном в обычном супермаркете 28.09.2026: без
кадрирования, с бликами, под углом, с соседними бутылками в кадре. Каждую
фотографию разметили вручную по каталогу (центральная бутылка — цель):

- **17 вин есть в каталоге** «Своё Вино» (Массандра, Шато Пино, Le Grand Vostock,
  Дербент Вино, Кубань-Вино, Инкерман, Раевское, Бурлюк);
- **67 вин в каталоге нет**: импорт (Италия, Испания, Германия, Грузия, Чили…) и
  российские линейки, которых нет в каталоге (Инкерман «Классическая коллекция»,
  Chateau Tamagne Nature Violet — в каталоге есть только Orange и Vert, и т. п.).

Фотографии в репозиторий не входят; результаты получены тем же API, что и в демо.

## Что изменилось после проверки

Первый прогон дал 12/17. Разбор ошибок показал три общие причины, не связанные с
конкретными фото:

1. OCR иногда выдаёт **греческие** буквы вместо кириллических («ΑЛΥШТА», «ΔЕΡБЕНТ»);
   добавлена замена греческих двойников.
2. Текст соседних бутылок (левая «CABERNET», правая «blanc») перебивал центральную;
   усилен приоритет центра кадра, а цвет и сладость определяются голосованием слов
   с весом по центральности. Добавлены «rouge», «tinto», «rosato», «secco» и др.
3. Softmax-вероятность относительна: импортное вино «выигрывает» у слабых кандидатов.
   Добавлена отдельная модель «есть ли вино в каталоге» по абсолютным признакам
   (inliers RootSIFT, визуальное сходство, покрытие текста), обученная с leave-one-out
   на реальных фото (`training/fit_open_set.py`). Порог выбран так, чтобы ни одно
   вино из каталога не получало «нет в каталоге».

Доля аугментации «эталон ≠ этикетка» (0,2) проверена на реальных фото: при 0,3–0,5
точность падала до 71–76%, поэтому значение не менялось.
